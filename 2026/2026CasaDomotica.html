¿Cómo funciona nuestra Casa Domótica?

La perfecta combinación entre desarrollo de software web frontend y programación de microcontroladores.

1. Interfaz Web (UI)

Un panel interactivo diseñado con HTML y CSS que emula el plano de la casa. Permite encender o apagar habitaciones de manera individual, o realizar acciones conjuntas, usando el ratón o teclas de atajo rápidas.

2. Canal de Comunicación

A través de la tecnología Web Serial API, el navegador web se conecta directamente de forma física al puerto serie USB del ordenador, enviando caracteres simplificados como comandos instantáneos a Arduino.

3. Procesador y Actuadores

Una placa Arduino Uno lee estos caracteres a 9600 baudios y conmuta el estado lógico de los pines digitales D2 a D5, los cuales activan relés físicos con lógica inversa.

💡

La solución inteligente: El auto-apagado

Un aspecto crítico de este sistema es la seguridad. El código web de control está programado con un mecanismo de auto-reseteo. En el momento en que se pierde la conexión o el usuario pulsa "Desconectar", la interfaz de la web apaga inmediatamente todas las bombillas virtuales por seguridad, sincronizándose con la desactivación física del circuito de relés.

Componentes de Hardware

Los elementos electrónicos que dan vida y materializan las órdenes que viajan desde la pantalla.

Placa compatible con Arduino UNO

Actúa como cerebro principal. Escucha constantemente el puerto de comunicaciones por si entra algún comando emitido desde la interfaz web de la casa.

Módulo de 4 Relés de Nivel Bajo (Low Active)

Permite aislar y conmutar de forma segura circuitos independientes de corriente. Al funcionar a nivel bajo (LOW), se activan cuando reciben un '0' lógico en su correspondiente pin de control (D2-D5).

Lámparas / LEDs (Emuladores de iluminación)

Representan la iluminación física real de las cuatro dependencias del plano de la vivienda.

Planificación del Software

El sistema se compone de dos programas coordinados que se comunican mediante protocolo serie.

Programa de Arduino (.ino)

InterfazCasa.ino

Se encarga de inicializar los pines D2 a D5 en modo de salida, apagar por defecto los relés (configurando el pin a HIGH), escuchar el puerto serie a 9600 baudios y aplicar los cambios lógicos en las salidas en base a los comandos recibidos.

// Pines D2, D3, D4, D5
const int pins[] = {2, 3, 4, 5};
bool estado[4] = {false, false, false, false};

void setup() {
  for (int i = 0; i < 4; i++) {
    pinMode(pins[i], OUTPUT);
    digitalWrite(pins[i], HIGH);  // Relé desactivado
  }
  Serial.begin(9600);
}

void loop() {
  if (Serial.available()) {
    char cmd = Serial.read();
    if (cmd >= '1' && cmd <= '4') {
      int idx = cmd - '1';
      estado[idx] = !estado[idx];
      digitalWrite(pins[idx], estado[idx] ? LOW : HIGH);
    }
    else if (cmd == 'A' || cmd == 'a') {
      for (int i = 0; i < 4; i++) {
        digitalWrite(pins[i], HIGH);
        estado[i] = false;
      }
    }
    else if (cmd == 'E' || cmd == 'e') {
      for (int i = 0; i < 4; i++) {
        digitalWrite(pins[i], LOW);
        estado[i] = true;
      }
    }
  }
}

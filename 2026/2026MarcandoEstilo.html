01. ¿En qué consiste el proyecto?

Este proyecto ha sido desarrollado como una práctica avanzada para la materia de Tecnología de 4º de la ESO. El objetivo es crear un puente de comunicación directa entre el mundo físico (un chip microcontrolador Arduino con un display de 7 segmentos real) y el mundo digital (un navegador web interactivo).

En lugar de requerir software adicional o drivers complejos, el proyecto hace uso del estándar moderno Web Serial API, permitiendo al ordenador enviar y recibir comandos binarios directamente desde el navegador de internet con solo pulsar un botón en pantalla o en el teclado.

Bidireccional

Si pulsas en la web, el Arduino físico cambia. Si el Arduino cambia mediante un botón físico, la web se actualiza al instante.

Hexadecimal (0-F)

El contador abarca desde el número 0 hasta el 15, permitiendo al alumnado entender de forma práctica la notación Hexadecimal (0 a F).

El Viaje de la Información

¿Cómo se transforma un clic en la pantalla en una señal eléctrica real? Sigue el flujo del dato a través de las 4 etapas tecnológicas del proyecto:

01
Origen (Software)

La Interfaz de Usuario

El alumno interacciona con la web (HTML/CSS) pulsando 'U' (Arriba), 'D' (Abajo) o 'R' (Reset). JavaScript captura este evento de forma asíncrona.

Dato Generado: Byte ASCII
02
Canal de Enlace

Web Serial API & USB

El navegador usa la Web Serial API para abrir un puerto de comunicación directa COM. El byte se transmite serialmente a través del cable USB a una velocidad de 9600 baudios.

Velocidad: 9600 bps
03
Cerebro (Proceso)

Procesamiento Arduino

El microcontrolador **ATmega328P** lee el búfer serie. Incrementa o decrementa la variable count y busca en su memoria la máscara de bits para el dígito.

Hardware: ATmega328P
04
Destino (Físico)

Señales en Display

Arduino pone los pines digitales del **D2 al D8** en estado HIGH o LOW. Los electrones fluyen a través de las resistencias de 220Ω, encendiendo los LEDs del display de cátodo común.

Voltajes: 0V - 5V

03. Conexiones y Electrónica

El conexionado de un display de 7 segmentos requiere especial atención al uso de resistencias limitadoras para proteger cada diodo LED de sobrecorrientes.

Resistencia recomendada: 220Ω

¡Atención! Nunca omitas las resistencias en los displays de 7 segmentos. Sin ellas, puedes dañar permanentemente el pin del microcontrolador o quemar los filamentos del display.

La Electrónica del Cátodo Común

En este proyecto de aula trabajamos exclusivamente con displays de tipo Cátodo Común:

¿Cómo funciona internamente?

Todos los terminales negativos (cátodos) de los 7 diodos LED internos están soldados juntos en una sola patilla común. Esta patilla común se conecta directamente al terminal de tierra o **GND (0V)** de la placa Arduino.

Lógica de Activación Directa

Para encender cualquier segmento (A, B, C, D, E, F, G), simplemente enviamos una señal de **HIGH (5V)** desde su pin digital correspondiente en el Arduino. Al enviar **LOW (0V)**, el segmento se apaga.

Nota didáctica: Al unificar nuestro hardware bajo el estándar de cátodo común, el código fuente de Arduino se simplifica enormemente, eliminando la necesidad de aplicar lógica inversa o invertir máscaras de bits.

05. Protocolo de Comunicación Web Serial

La Web Serial API permite que páginas web seguras (HTTPS) abran directamente la comunicación serie asíncrona del puerto USB local del usuario. Es una de las tecnologías más disruptivas para el aprendizaje de la robótica y la electrónica escolar, ya que elimina barreras de instalación de software pesado.

Protocolo del proyecto (9600 Baudios):

Web -> Arduino: Envía un solo carácter sin retorno de carro para realizar una acción directa.
'U' para Incrementar (Up), 'D' para Decrementar (Down), 'R' para Restablecer (Reset).
Arduino -> Web: Cada vez que el contador cambia, Arduino responde enviando el valor del contador actual en notación hexadecimal (un carácter de '0' a 'F') seguido de un salto de línea (\n).
